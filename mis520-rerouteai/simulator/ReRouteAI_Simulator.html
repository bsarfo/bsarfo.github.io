Each line is one route's expected cost. The lowest line wins; where lines cross, the recommendation flips. The band on top shows the winner across the range.

Nodes are "landed at airport X at time t". Edges are flights you can still make (minimum connection time and seats respected). Edge weight = value of time × minutes + cash + 200 × (−ln P), so connection probabilities add up along a path and Dijkstra stays exact. A* adds a heuristic: the fastest possible remaining flying time, which never overestimates.
